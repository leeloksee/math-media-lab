# 排水法（二）：Q6–Q8 與跟進練習簡版

香港小學數學 · 互動 3D 教師預覽示範（排水法第二課筆記對應）。

## 開啟方式

**建議（本地伺服器，支援 ES modules）：**

```bash
cd /workspace/math-media-lab/water-displacement
python3 -m http.server 8765
```

然後在瀏覽器開啟：`http://localhost:8765/`  
（iPad 請用同一 Wi‑Fi 下電腦的 IP，例如 `http://192.168.x.x:8765/`）

亦可直接打開 `index.html`；若 `file://` 下 ES module 空白，請改用上方本機伺服器。

## 題目導航

- **可自由跳題**（非鎖步）：頂部 ① Q6 → ② Q7 → ③ Q8 → ④ 跟進練習簡版
- 各鈕標有「建議」順序，但不強制

## 內容對應

| 題 | 重點 | 答案 |
|----|------|------|
| Q6 | 長 40×闊 28，石橋 896 cm³，初水位 20 | 上升 896÷40÷28 = **0.8 cm** |
| Q7 | 25×18，石屋 900 cm³，初水位 11 | 新水位 11+900÷25÷18 = **13 cm** |
| Q8 | 邊長 10，錦鯉 200 cm³，現水位 6（物體在內） | 取出後 6−200÷10÷10 = **4 cm** |
| 跟進1 | 底面積 18，上升 3；紅 6 / 綠 5 | 18×3=**54**；4紅+6綠 |
| 跟進2 | 底面積 20，下降 4；白 7 / 黑 8 | 20×4=**80**；8白+3黑（見教師備註原稿差異說明） |

## 技術堆疊

- **Three.js r160**（本地 `vendor/`）+ **OrbitControls**
- 純 HTML / CSS / JS，無建置、無 CDN、完全離線
- iPad 友善大觸控目標；繁中介面；軟色童趣風格

## 操作

- 拖曳旋轉、滾輪／雙指縮放
- Q6／Q7：放入 → 水位上升＋綠色帶；Q8：取出 → 水位下降＋橙色帶
- 「顯示計算過程」預設關閉，方便先問再講
- 「教師備註」可收合，含答案與跟進2原稿數字說明
